# The Xolo Concilium — Section Plan

Section for The Creature Committee Etsy shop, dedicated to the Xoloitzcuintli (Mexican hairless dog).

> Status key: **LOCKED** = approved by YEX · **PROPOSED** = awaiting approval · nothing here is published.

## Stage 1 — Section concepts (LOCKED 2026-11-06)

- **Section name:** The Xolo Concilium (Latin for "council"; renamed from "The Xolo Council" on 2026-11-06)
- **Launch order:**
  1. **Sweater Weather** (holiday; time-sensitive)
  2. **Committee Officials** (brand signature)
  3. **Guardian of Mictlán** (Día de Muertos and memorial ornament, sold all year)
  4. **Coat & Size Variants** (variant system applied across 1–3)
- **Approved artwork:** XC-SW-02 v3 "Xolo Fair Isle" (Canva MAHaK8ojvDU), 2026-11-06
- **Later tests:** Hairless Humor, Modern Silhouette
- **"CREATURE COMMITTEE" text on artwork (locked 2026-11-06):**
  - Existing approved designs keep their current text as-is. For example, Blanket Affairs and Sun Patch Society keep it, and Ancient Soul v2 stays without it.
  - **New designs do not add it** until YEX changes this rule.
- **Reusable style:** Botanical Relief Print skill at `.claude/skills/botanical-relief-print/`, with the El Compañero reference image in `references/`.
- **Guardrails:**
  - No *Coco*/Dante or Disney/Pixar references.
  - No "Naked and Afraid" title riffs.
  - Treat Aztec and Día de Muertos imagery as respectful folk art.
  - Every listing description includes: "Artwork created with the help of AI tools".

Research gap: live Etsy competitor review not done (etsy.com is blocked in the session network). Concepts are based on what owners care about, not on proven sales.
